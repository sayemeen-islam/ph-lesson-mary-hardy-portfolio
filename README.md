# 💻 Mary Hardy Portfolio Website

### [🔗 Live Site Link](https://sayemeen-islam.github.io/ph-lesson-mary-hardy-portfolio/) | [💻 Code Repository](https://github.com/sayemeen-islam/ph-lesson-mary-hardy-portfolio)

---

## 📝 Overview
This project is a clean, multi-section developer portfolio layout based on the Mary Hardy design challenge. It was built as a structured HTML/CSS practice task to learn layout flows, background positioning, and styling structures.

---

## 🚀 Main Features
- **Semantic Structure**: Uses meaningful HTML5 tags like headers, sections, and navigation structures.
- **Detailed Layouts**: Features dedicated blocks for personal introductions, skills, education timelines, and a contact form.
- **Custom Styling**: Implements exact color pickers, margins, paddings, and button custom styles.

---

## 🛠️ Technologies Used
- **HTML5**: Core page content and layout architecture.
- **CSS3**: Custom layouts, font stylings, and interface components.

---

## 📦 Key Dependencies
- **No External Dependencies**: Built entirely with native web standards. No external framework or packages are required.

---

## 💻 How to Run This Project Locally
To run this project on your computer, follow these two quick steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sayemeen-islam/ph-lesson-mary-hardy-portfolio.git
   ```
2. **Open the project:**
   - Go inside the folder and double-click the `index.html` file to open it instantly in your web browser.
